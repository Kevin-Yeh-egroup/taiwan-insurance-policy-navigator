User Manual

操作手冊

保單來源查詢、篩選、判讀與複核流程。

查詢台 操作手冊

Start

1. 開始查詢

  1. 在「查詢來源」輸入保險公司、商品名稱、關鍵字、網域或 PDF 連結片段。
  2. 按「查詢」。系統會顯示符合條件的官方來源清冊。
  3. 需要重來時按「清除條件」。

Filters

2. 用篩選縮小範圍

  1. 「保險公司」用來只看單一公司的來源。
  2. 「資料類型」可切換商品頁、PDF/檔案、法規/公會、社會保險等來源。
  3. 「狀態」可快速查看可開啟、網站限制、需人工確認或尚未檢查的來源。

Insights

3. 看懂保單重點總覽

  1. 「已整理保單」是從目前文件欄位抽出的保單筆數。
  2. 「已停售」「仍可投保」「待確認」用來快速判斷後續複核優先順序。
  3. 「商品類型」與「公司分布」可看出資料集中在哪些保險公司與險種。
  4. 「保發中心停售查詢」顯示官方查詢入口可用欄位與圖形驗證碼限制。

Cards

4. 看懂來源卡片

  1. 第一行是保險公司與來源狀態。
  2. 標題下方會顯示資料類型、是否為公開候選，以及來源網域。
  3. 按「開啟來源」會到保險公司、主管機關或公開來源頁面。
  4. 按「來源資訊」可查看原始連結、HTTP 狀態、內容類型、檢查時間與狀態說明。

Status

5. 判讀狀態

狀態 意思 建議動作
可開啟 來源已完成連線檢查，可作為查找入口。 仍需回官方頁面或正式條款確認。
網站限制 站方 robots 規則不允許自動抓取。 用「開啟來源」手動檢查官方頁。
需人工確認 連線、格式或伺服器回應異常。 排入內部複核，不要直接當成資料不存在。
尚未檢查 來源已在清冊中，但尚未進入批次檢查。 等待下一批檢查或人工開啟來源。

Reader Questions

6. 民眾查保單最在乎的七件事

  1. 理賠內容：發生什麼事可以申請、給付條件與申請文件。
  2. 名詞定義：疾病、醫院、住院、手術、意外等正式定義。
  3. 等待期/免責期：多久後開始有保障、多久後起賠。
  4. 除外責任：哪些情況不在保障範圍。
  5. 保費與續保：費率、續保、停效、復效與解約費用。
  6. 投保限制：年齡、保額、職業、健康告知與附約限制。
  7. 官方文件：條款、商品說明書、費率表、文號與版本日期。

Limits

7. 重要限制

本站是公開資訊整理與導覽工具，不是保險建議、法律意見、理賠承諾或承保判斷。所有摘要、狀態與欄位都應回到保險公司、主管機關或官方條款確認。

「可開啟」只代表來源連線可用，不代表保單條款已完成法律或專業審閱。「網站限制」或「需人工確認」也不代表商品不存在或無法申請理賠。

Batch

8. 大量保單分段處理

保單很多時，系統會拆成「保單 URL 自動批次」與「TII 人工驗證碼批次」。每批都有 ID、筆數、公司、類型與處理方式。TII 批次需要人工輸入驗證碼並保存結果，再由匯入器整理。

目前 policy-url-001 到 policy-url-017 已執行完成，共處理 1,343 筆保單 URL，其中 559 筆可抓取、532 筆受 robots 限制、252 筆錯誤或逾時。批次完成代表已檢查，不代表每一筆都能自動整理出完整保單內容。
