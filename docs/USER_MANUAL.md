# 保單資訊查詢台操作手冊

Production 手冊頁：<https://taiwan-insurance-policy-navigator.vercel.app/manual.html>

## 1. 開始查詢

1. 在「查詢來源」輸入保險公司、商品名稱、關鍵字、網域或 PDF 連結片段。
2. 按「查詢」。
3. 需要重來時按「清除條件」。

## 2. 用篩選縮小範圍

- 「保險公司」只看單一公司。
- 「資料類型」切換商品頁、PDF/檔案、法規/公會、社會保險等來源。
- 「狀態」切換可開啟、網站限制、需人工確認或尚未檢查。

## 3. 看懂保單重點總覽

- 「已整理保單」是從目前文件欄位抽出的保單筆數。
- 「已停售」「仍可投保」「待確認」用來快速判斷後續複核優先順序。
- 「商品類型」與「公司分布」可看出資料集中在哪些保險公司與險種。
- 「保發中心停售查詢」顯示官方查詢入口可用欄位與圖形驗證碼限制。

截圖：`assets/manual/policy-insights.png`

## 4. 看懂來源卡片

- 第一行是保險公司與來源狀態。
- 標題下方顯示資料類型、公開候選與來源網域。
- 「開啟來源」會到保險公司、主管機關或公開來源頁面。
- 「來源資訊」可查看原始連結、HTTP 狀態、內容類型、檢查時間與狀態說明。

## 5. 判讀狀態

| 狀態 | 意思 | 建議動作 |
| --- | --- | --- |
| 可開啟 | 來源已完成連線檢查，可作為查找入口。 | 仍需回官方頁面或正式條款確認。 |
| 網站限制 | 站方 robots 規則不允許自動抓取。 | 用「開啟來源」手動檢查官方頁。 |
| 需人工確認 | 連線、格式或伺服器回應異常。 | 排入內部複核，不要直接當成資料不存在。 |
| 尚未檢查 | 來源已在清冊中，但尚未進入批次檢查。 | 等待下一批檢查或人工開啟來源。 |

## 6. 重要限制

本站是公開資訊整理與導覽工具，不是保險建議、法律意見、理賠承諾或承保判斷。所有摘要、狀態與欄位都應回到保險公司、主管機關或官方條款確認。

「可開啟」只代表來源連線可用，不代表保單條款已完成法律或專業審閱。「網站限制」或「需人工確認」也不代表商品不存在或無法申請理賠。

## 7. 大量保單分段處理

保單很多時，系統會拆成「保單 URL 自動批次」與「TII 人工驗證碼批次」。每批都有 ID、筆數、公司、類型與處理方式。TII 批次需要人工輸入驗證碼並保存結果，再由匯入器整理。
