# 保單資訊查詢台操作手冊

Production URL: <https://taiwan-insurance-policy-navigator.vercel.app/>

手冊網頁: <https://taiwan-insurance-policy-navigator.vercel.app/manual.html>

## 1. 開始查詢

1. 打開首頁後，在「查保單重點」輸入保險公司、商品名稱、住院、手術、除外責任、等待期等關鍵字。
2. 按「查詢」或按 Enter，保單快讀卡會立即依條件更新。
3. 需要重新開始時，按「清除條件」回到完整資料集。

## 2. 用篩選縮小範圍

- 「公司」適合先找特定保險公司。
- 「保單類型」可切換壽險、健康險、傷害險、年金險等類型。
- 「重點狀態」可快速查看四項都有、有特殊項目、需回官方確認。

## 3. 看懂圖像化重點

- 「保單快讀卡」是主要工作區，每張卡固定呈現保障項目、重要定義、特殊項目、理賠申請。
- 每個重點區塊會列出命中詞與頁碼提示，方便回官方條款複核。
- 「來源總覽」先看目前有多少來源、多少已檢查、多少可開啟。
- 「保單內容抽取」確認系統是否真的讀到保單 PDF/HTML 內容。
- 「重點欄位命中」顯示理賠/給付、名詞定義、除外責任、等待期、保費續保、投保限制等欄位的命中數。
- 「抽取範例」可看到實際保單、解析頁數、文字量與命中欄位，並可直接開啟官方來源。

## 4. 閱讀來源卡片

- 每張卡片代表一個官方來源 URL。
- 優先看公司、來源類型、抓取狀態與 HTTP 狀態。
- 按「開啟來源」可到保險公司或官方網站確認原始文件。
- 按「複製連結」可把官方來源貼給同事或後續查核。

## 5. 狀態說明

| 狀態 | 意義 | 建議動作 |
| --- | --- | --- |
| 可開啟 | 網站允許讀取，且來源目前可取得 | 可進一步查看或整理條款重點 |
| 網站限制 | robots 規則不允許自動抓取 | 保留網址，不做自動內容抽取 |
| 需人工確認 | 來源逾時、錯誤、404 或格式待確認 | 後續人工重新檢查 |
| 人工驗證 | 保發中心停售查詢有圖形驗證碼 | 只能人工完成驗證碼後匯入結果 |

## 6. 一般民眾最常問的重點

1. 這張保單哪些情況會理賠或給付？
2. 重要名詞怎麼定義，例如疾病、傷害、住院、手術？
3. 是否有等待期、免責期或不賠條件？
4. 除外責任有哪些？
5. 保費、續保、停效、解約或取消有哪些限制？
6. 投保年齡、職業、健康告知或承保限制是什麼？
7. 官方文件在哪裡，能不能回到原始來源確認？

## 7. 目前資料進度

批次分成兩種，不是只有 `17` 批。

自動保單 URL 批次 `policy-url-001` 到 `policy-url-017` 已完成，共處理 `1,343` 個保單 URL。其中 `559` 個可讀取，`532` 個受 robots 規則限制，`252` 個錯誤或逾時。

內容抽取已完成所有 `559` 個可讀取來源，包含 `551` 筆 PDF 與 `8` 筆 HTML。系統共解析 `6,373,892` 個文字字元，`555` 筆來源命中至少一個民眾關心欄位。讀者快讀卡命中情形為：保障項目 `553` 筆、重要定義 `552` 筆、特殊項目 `529` 筆、理賠申請 `539` 筆。

## 8. 保發中心停售保單

保發中心 TII 是另一組人工驗證碼批次。保發中心查詢頁分為產險與壽險/人身險，網站目前已建立 `108` 個產險人工查詢批次與 `198` 個壽險/人身險人工查詢批次，合計 `306` 個人工批次。

目前 TII 執行狀態是已啟動 `1 / 306` 個人工批次，其中 `1` 個等待人工輸入驗證碼，`0 / 306` 個人工批次完成、`0` 筆 TII 保單結果匯入。因查詢結果需要圖形驗證碼，本專案不破解驗證碼。可在網站上逐批開啟查詢頁，人工完成驗證後再匯入結果。
